# Mohammed Firas Ghannam — Academic Portfolio

A minimal, responsive, static academic website built for GitHub Pages. No coding tools or installs required to publish it.

## Preview before publishing

1. Unzip this package.
2. Open `index.html` in your web browser. You can navigate between the Home, Research and Writing pages.
3. The site can work offline, though its optional Google Fonts require an internet connection.

## Publish on GitHub Pages — beginner instructions

1. Register or sign in at https://github.com/.
2. Create a **new public repository** named EXACTLY `YOURUSERNAME.github.io` (replace YOURUSERNAME with your actual GitHub username, using lowercase if applicable).
3. You can choose **Add a README** when creating the repository; that is optional.
4. Go to the repository's **Code** tab. Click **Add file → Upload files**. If this menu is not shown, use the **uploading an existing file** link.
5. Unzip this package on your computer and open the extracted folder. Upload these items from inside the folder: `index.html`, `research.html`, `writing.html`, `styles.css`, `script.js`, `README.md`, `.nojekyll`, and the `assets` folder **with all its contents**. Make sure `index.html` is in the root, NOT inside an extra folder.
6. Click **Commit changes**.
7. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Set **main** and **/(root)**, then Save.
8. Visit `https://YOURUSERNAME.github.io/` (publication can take up to 10 minutes).

Official documentation: https://docs.github.com/en/pages/quickstart

## How to edit text later

- Open a file on GitHub and click the pencil (Edit) icon to update text; select **Commit changes** to publish.
- To replace the portrait, keep the same filename `assets/mohammed-ghannam-portrait.webp` and upload a new file with that name.
- Send the website files back to ChatGPT when ready to add the full article; a complete article page, publication card and links can then be integrated.

Designed as a simple static site so there are no dependencies, servers or build steps.
